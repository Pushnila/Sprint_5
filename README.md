# Sprint 5 — Selenium UI tests

Автотесты для учебного сервиса
[Stellar Burgers](https://stellarburgers.education-services.ru/).

## Проверенные сценарии

- успешная регистрация;
- сообщение об ошибке для пароля короче шести символов;
- вход с главной страницы;
- вход через «Личный Кабинет»;
- вход из форм регистрации и восстановления пароля;
- переход в личный кабинет;
- переход из профиля в конструктор по ссылке и логотипу;
- выход из аккаунта;
- переключение разделов «Булки», «Соусы» и «Начинки».

## Структура

- `tests/` — тесты, сгруппированные по функциональности;
- `conftest.py` — фикстура браузера;
- `locators.py` — локаторы с комментариями;
- `helpers.py` — генераторы данных и общие шаги;
- `data.py` — адреса страниц и тестовые данные.

## Запуск

Установить зависимости:

```shell
python -m pip install -r requirements.txt
```

Запустить тесты в Google Chrome:

```shell
python -m pytest -v
```
